previous range. All C routines get the mg pointer with `sub_01000686` (= `vbr[4]`, i.e. the

Machine-type gate used everywhere in the Ethernet code: `mg+$194 == $139` means "old I/O"
(set at `$01000d32`/`$01000d3c` for machine types 0..3, i.e. all non-Turbo boards);

## Console layer ($01008140..$0100822a)

The three function pointers installed at `$01000f34` into mg+$2D6/$2DA/$2DE are, in the NetBSD
`mon_global` order, `mg_getc`, `mg_try_getc`, `mg_putc`.

### `sub_01008140` con_getc () -> d0 = char
Switch on `mg+$318` (input selector):
* 0 -> `sub_0100a3a6(0)` keyboard read through KMS (`sub_0100a2ba`); ignores $100, XON, XOFF; clears mg+4 bit0; CR -> LF.
* 1 -> `sub_01008c72(0)` SCC, control reg `$02118001` (channel A).
* 2 -> `sub_01008c72(1)` SCC, control reg `$02118000` (channel B).
* anything else -> returns without reading (d0 = selector value; `sub_01007b76`'s line editor loops on it).
Caller: `$01007b76` (line input, `mg_inputline`).

### `sub_01008184` con_try_getc () -> d0 = 1 if a key is pending
Same switch on `mg+$318`: 0 -> `sub_0100a06c` (mg+4 bit0, or ADB/mouse via `sub_0100d032` when
mg+$3E5 bit0), 1/2 -> `sub_01008cd6` (returns and clears mg+4 bit4). Used by `$01005c8c` to abort
a wait loop on any key press.

### `sub_010081c8` con_putc (char at $b(a6)) 
Switch on `mg+$31C` (output selector):
* 0 -> `sub_0100a118(0, c)` screen putc. If it returns 0 (the screen driver could not print, e.g.
  `sub_010098a4` just re-routed the console to the serial port) the loop re-reads `mg+$31C` and
  retries with the new selector.
* 1 -> `sub_01008cf4(0, c)` SCC A, 2 -> `sub_01008cf4(1, c)` SCC B, else drop.
Callers: `$01007494`/`$010074a4` (putchar with LF -> CR LF expansion).

Note there is no fourth "screen" case: the screen is selector 0 for output and the keyboard is
selector 0 for input; the serial console is selected by writing 1 to both (done by
`sub_010098a4` when no keyboard answers and NVRAM alt-cons is set).

## RTC / NVRAM bit-bang ($0100822c..$01008898)

The RTC is reached only through SCR2 (`$0200D000`, byte 2): `$100` = RTCE (chip enable),
`$200` = RTCLK, `$400` = RTDATA (sysReg.c). Base value `d5 = SCR2 & $FFFFF8FF`. Every edge is
separated by `sub_0100822c` = `delay_us(1)` (actually ~2 ticks of the 1 MHz counter).

### `sub_010087e8` rtc_read_reg_raw (reg) / `sub_010087cc` rtc_read_reg (reg) -> byte
1. `SCR2 = base | $100` (CE high), delay.
2. 8 address bits MSB first: `SCR2 = base|$100|(bit?$400:0)` (CLK low), delay; `|= $200` (CLK high), delay; `&= ~$200` (CLK low), delay.
3. 8 data bits MSB first: `SCR2 = base|$300` (CLK high), delay; `SCR2 = base|$100` (CLK low), delay; sample `SCR2 & $400` -> bit; delay.
4. `SCR2 = base` (CE low). Data is therefore shifted out by the chip on the falling clock edge and
   sampled by the ROM after the fall.

### `sub_010086e8` rtc_write_reg (reg, val)
Same as above but the address is `reg | $80` and step 3 shifts out 8 data bits the same way as the address bits. Ends with `SCR2 = base`.

`sub_01008790` (reg, buf, n) reads n consecutive registers. `sub_0100828c` (reg, mask, val) is a read-modify-write.

### NVRAM
* `sub_0100861c` nvram_read (buf): regs $00..$1F -> buf; checksum = `~sub_0100743c(buf, 32)` (word at buf+$1E is zeroed first) must equal the stored word; d0 = 0 ok / -1 bad.
* `sub_0100866c` nvram_write (buf): stores `~checksum` at +$1E, writes regs $80..$9F, then re-reads with nvram_read into a stack copy and `strcmp`s (sic, `sub_010080d8`, so a zero byte stops the compare early); 0 ok / -1.
NVRAM layout: rtcnvram.c 880-950 (byte 0 bit3 = alt cons, byte 14 = POT, byte 17 bit7 = new clock chip).

### Time
* `sub_010084d6` rtc_get_time () -> d0 seconds since 1970, d1 = 0. Status reg `$30`: bit4 FIRSTUP -> 0. Bit7 set (MCCS1850, "new chip") -> 4 bytes `$20..$23` big-endian counter. Old chip (MC68HC68T1): reads `$20..$27` repeatedly until the seconds byte is stable, BCD->bin (`sub_010085ec`) for sec/min/hour/mday/month/year (weekday `$23` skipped), then `sub_01008440`.
* `sub_01008440` tm_to_secs: days = sum over years 70..(year-1) of 365 (+1 if `year%4==0`), + `dat_0101a8a2[month]` (cumulative days table, 13 words at `$0101a8a2`: 0,0,31,59,90,120,151,181,212,243,273,304,334) + mday-1 (+1 if leap and month>2); seconds = days*86400 + h*3600 + m*60 + s. Years are 1900-relative; no Y2K handling (year<70 is treated as before 1970).
* `sub_0100823e` rtc_wait_tick: polls reg `$23` (new chip, low counter byte) or `$20` (old) every 1000 us until it changes.

### Power / interrupts
* `sub_010082ca` rtc_power_int_handler: `while (*(mg+$19C) & INT_POWER(4))`: read `$30`; old chip (bit7 clear) -> return 1. New chip: bit4 FIRSTUP -> `$31 |= 4` (CLRFTU); bit2 LBAT -> `$31 &= ~2` (LBE off); bit1 ALARM -> `$31 |= 8`; bit0 PDOWN -> `$31 |= 1` (CLRPDOWN) and result = 1. Returns 1 if a power-down request was seen. Called from `sub_010098a4` and the power-button paths (`$0100a1ca`, `$0100a234`, `$0100a272`).
* `sub_01008380` rtc_power_down: new chip: wait tick, `delay_us(850000)`; then `$31` (new) / `$32` (old) `|= $40` (POWERDOWN); `bra.b *` forever.
* `sub_010083d4`: old chip: `$32 = 0` (all RTC interrupts off); then `sub_010082ca`.
* `sub_01008400` rtc_start_clock (called from `$010052da`): `sub_010083d4`; new chip `$31 |= $80` (START); old chip `$31 = $B0` (START | XTAL sel 3 = 32.768 kHz, clock-out off).

## Microsecond timer ($0100889c..$01008962)

`sub_0100889c` timer_read_us: reads the event counter byte-wise at `$0211A000..3` (mirror of
`$0201A000`; the byte at +0 is read but discarded, +1 gives bits 19:16, +2 bits 15:8, +3 bits 7:0)
-> 20-bit count. `mg+$2F6` holds the software high part: if bit 19 of (count ^ high) is set the
counter wrapped, so `high += $80000`; returns `high | count`. `sub_0100890e` = /1000,
`sub_01008924` (t0) = now - t0, `sub_01008936` (n) = busy-wait until elapsed > n (n+1 ticks).
All ROM delays are in microseconds; the FPGA core needs this counter running at 1 MHz.

## SCC Z8530 ($01008964..$01008d72)

Addresses (mirror of `$02018000`): `$02118000` = channel B control, `$02118001` = channel A
control, data register = control+2. Port argument 0 = channel A (`$02118001`), 1 = channel B.
Console selector 1 (SCC A) maps to port 0, selector 2 to port 1. Each register write is
preceded by a 1-iteration `subq/tst/bgt` settle loop (a few cycles, not a real delay).

### `sub_01008964` scc_init ()
1. `$02118001 <- $09` then `$02118001 <- $C0` (WR9 = force hardware reset, both channels).
2. `delay_us(10)`.
3. `sub_010089cc($02118001, 9600)` channel A, then `sub_010089cc($02118000, 9600)` channel B.
4. `mg+4 &= $CF` (clear XOFF and pending-char flags). Caller sets bit6 before calling.
Called from `$010019de` (init), `sub_01008c72`, `sub_01008cf4` (lazily on first use).

### `sub_010089cc` scc_init_channel (ctrl, baud)
Writes to the control register, in this order (register index byte, then value byte):
| # | write | meaning |
|---|---|---|
| 1 | `09`, `02` | WR9 = NV (no vector), interrupts off |
| 2 | `0B`, `50` | WR11 = Rx clock BRG, Tx clock BRG, RTxC = crystal input off |
| 3 | `30` | WR0 command 6: Error reset |
| 4 | `10` | WR0 command 2: Reset Ext/Status interrupts |
| 5 | `04`, `44` | WR4 = x16 clock, 1 stop bit, no parity |
| 6 | `03`, `C0` | WR3 = Rx 8 bits/char, receiver disabled |
| 7 | `05`, `60` | WR5 = Tx 8 bits/char, transmitter disabled |
| 8 | `0E`, `00` | WR14 = BRG off |
| - | `tc = sub_01008b30(baud, 16)` | (this call writes the clock select register, see below) |
| 9 | `0C`, `tc & $FF` | WR12 = time constant low (9600: $0A) |
| 10 | `0D`, `tc >> 8` | WR13 = time constant high (0) |
| 11 | `0E`, `tc >> 16` | WR14 = BRG source: $02 = PCLK (9600 baud case), $00 = RTxC |
| - | `delay_us(10)` | |
| 12 | `0E`, `(tc >> 16) | 1` | WR14 = BRG enable (9600: $03) |
| 13 | `03`, `C1` | WR3 = Rx 8 bits, Rx enable |
| 14 | `05`, `EA` | WR5 = DTR, Tx 8 bits, Tx enable, RTS |
Writes 3 and 4 have no settle loop between them (they follow WR11's value byte directly).

### `sub_01008b30` scc_calc_baud_tc (baud, divisor=16) -> tc
First writes the SCC clock select register `$02118004 <- $0A` (scc.c: bits 1:0 = channel A
clock = 4 MHz, bits 3:2 = channel B clock = 4 MHz, bits 5:4 = 0 = system PCLK 3.684 MHz).
Then for both entries of `dat_0101a93c` = {3686400 (PCLK), 4000000 (RTxC)}:
`tc = (clk + baud*div) / (2*baud*div) - 2`, `err = |(clk<<8) / ((tc+2)*2*div) - (baud<<8)|`
(`abs` = the missed routine at `$01007e0c`). If err[PCLK] < err[RTxC] returns `tc[PCLK] | $20000`
(so WR14 bit1 = BRG from PCLK), else `tc[RTxC] & $FFFF`. For 9600: PCLK gives tc = 10 exactly,
RTxC gives 11 with error, so 9600 = TC $000A, WR14 = $03, i.e. **9600 8N1 from the 3.6864 MHz PCLK**.

## Ethernet ($01008d74..$01009862)

Register map (`$02106000` = mirror of `$02006000`, ethernet.c): +0 TX status, +1 TX mask,
+2 RX status, +3 RX mask, +4 TX mode, +5 RX mode, +6 reset/control, +8..+D node ID.
TX DMA CSR `$02000110`, RX DMA CSR `$02000150`; each channel's next/limit/start/stop are at
CSR+$4000/+$4004/+$4008/+$400C (`$02004110..1C`, `$02004150..5C`). TDMA saved limit `$02004050`.
Interrupt: `INT_EN_RX_DMA = $08000000`, autovector 30 (vbr+$78, level 6). Bit names: dma.c 77-110
(non-Turbo commands) and 1098-1110 (Turbo extras: `$200000` SETCOMPLETE, `$400000` FLUSH,
`$800000` BUFRESET).

Driver state (allocated with `mg_alloc($1E0)`, pointer in netif+$24; netif pointer in mg+$176):
+0 initialised; +6 reg base; +$A TX CSR; +$E RX CSR; +$12 MAC[6]; +$18 RX DMA ring index
(producer, 0..31); +$1A consumer index; +$1C 32 x 14-byte ring entries {+0 buffer, +4 CSR snapshot,
+8 valid, +9 RX status, +$A saved limit}; +$1DC TX buffer.
Buffers are carved from the top of the highest populated bank: base = `(mg_region[i].last + 15) & ~15` for the
highest i with `mg+i != 0`; RX buffer k = base - $6000 - k*$2000 (k = 0..31), TX buffer = base - $6000 - 32*$2000.
Every register byte access goes through the bus-error-safe helpers `sub_0100237a`/`sub_010023b8`
(they park a continuation in mg+$1A4) wrapped by:
* `sub_01008d74` enet_reg_read (addr): 15 attempts, prints "enreg_read failed \n" on failure, returns the byte.
* `sub_01008dc0` enet_reg_write (addr, val): 15 attempts, prints "enreg_write failed \n".
* `sub_01008e0a` enet_reg_poll (addr): 10 attempts 1000 us apart; 1 = readable, 0 = bus error every time.

### `sub_01008e5e` enet_init (netif) -> d0 = pointer to MAC (state+$12), Turbo path
1. State struct allocated if netif+$24 == 0; if state+0 already set, return.
2. Buffer carve as above; each ring entry: buffer set, +4 = 0, +8 = 0, +9 = 0.
3. `$02106006 <- $80` (EN_RESET). (non-Turbo: then `<- 0`.)
4. `$02106001 <- 0` (TX mask), `$02106000 <- $FF` (clear TX status).
5. `$02106004 <- 0` (TX mode; non-Turbo `2` = DIS_LOOP).
6. Turbo: `$02106004 |= 4` (TXMODE_TPE, twisted pair), `delay_us(500000)`, `mg+$F0 = "en"`.
   (non-Turbo: BMAP+$34 |= $90000000 and TX mode &= ~2 when the interface name is "tp".)
7. `$02106003 <- 0` (RX mask), `$02106002 <- $FF` (clear RX status), both via enet_reg_write.
8. `$02106005 <- $80` (RX mode, Turbo RXMODE_ENABLE; non-Turbo 0) via enet_reg_write.
9. MAC: if ROM header bytes `$0100000B..D` != FF:FF:FF use the ROM MAC at `$01000008`, else NVRAM bytes 4..9 (mg+$1A). Copy to state+$12 and to `$02106008..$0210600D`.

RX DMA: indices = 0; `CSR $02000150 <- $00940000` = BUFRESET|DMA_RESET|DEV2M (non-Turbo `$00340000` = INITBUF|RESET|DEV2M); `$02004150 (next) <- rxbuf0`; `$02004154 (limit) <- rxbuf0 + $630`; Turbo only: `$0200411C <- rxbuf0` (TX channel stop register; purpose unknown, possibly the Turbo "saved next", flag as uncertain).

Caller `$01004c60` (netif setup, ops table `$0101a95c` = {enet_init, `sub_010095b2`, `sub_01009116`, `sub_0100928a`, `sub_01008e56`, 1}).

### `sub_010096be` enet_rx_dma_start (restart)
If !restart: RX CSR must have some of bits 27:24 set (else prints "i2"); if bit 24 (ENABLE) is still set skip to the chain step. Otherwise mark ring[+$18] with the CSR snapshot, +9 = 0, +8 = 1, `$02106002 <- $FF`, advance +$18 mod 32, then `next <- buf[+$18]`, `limit <- buf + $630`, Turbo: `$0200411C <- buf`; chain step: `start ($02004158) <- buf[(+$18+1) mod 32]`, `stop ($0200415C) <- buf + $630`; CSR command: `$000F0000` (SETENABLE|SETSUPDATE|DEV2M|CLRCOMPLETE) in the !restart path, restart path `$00070000` (SETENABLE|SETSUPDATE|DEV2M) when restart != 0, `$000E0000` otherwise. Finally reads CSR: bits 27:24 == 0 -> prints "i3"; bit 24 clear -> state+5 = 1 (DMA stalled flag, printed as "X" by enet_read). Buffer limit is always $630 = 1584 bytes.

### `sub_010095f0` enet_rx_int () (from `sub_01009102`, vector 30)
Up to 32 iterations: CSR bits 27:24 must be non-zero (else "i1"); ring[+$18].+4 = CSR; +9 = RX status (`$02106002`, safe read); +$A = `$02004050` saved limit (Turbo; non-Turbo `$02004144`); +8 = 1; `$02106002 <- $FF`; advance +$18; `sub_010096be(0)`.

### `sub_01009116` enet_read (buf, maxlen) -> length or 0
Turbo: read RX status; if bit7 (PKT_OK) set: `$02106002 <- $FF`, then RX mode `<- (RX mode | $80)`
(re-enable receiver). Prints "X" if state+5 set (and clears it). Entry = ring[+$1A]; if +8: len =
(saved limit & $3FFFFFFF) - buffer; Turbo: if bytes buffer+1..+6 equal our MAC or FF:FF:FF:FF:FF:FF, `bcopy(buffer+1, buffer, len-1)` (the AT&T chip deposits the frame one byte late; Previous models this as the "saved nibble"). Clear +8/+9/+4, advance +$1A. len must be 0..$62E (1582) else "L" printed and 0 returned; otherwise copy min(len, maxlen) to buf, return len.

### `sub_0100928a` enet_write (buf, len, tpcheck), Turbo path
* If tpcheck and TX mode bit2 (TPE) set: `$02106004 &= ~4` (drop TP), `delay_us(500000)`, `enet_reg_poll($02106002)`; if that fails or tpcheck cleared: `$02106004 |= 4`, delay 500 ms (thin-wire/TP toggle dance; on Turbo Color with TP only it ends with TPE set).
* `TX CSR $02000110 <- $00980000` = BUFRESET|RESET|CLRCOMPLETE (non-Turbo `$00380000`), then `<- 0`.
* `bcopy(buf, txbuf, len)`; `$02004110 (next) <- txbuf`; Turbo `$02004118 (start) <- txbuf` (non-Turbo `$02004100`); `$02004114 (limit) <- txbuf + len` (non-Turbo `| $80000000 + 15`, also to `$02004104`).
* `TX CSR <- $00010000` (SETENABLE). Turbo: `$02106004 |= $80` (TXMODE_ENABLE).
* Wait up to 300000 polls for TX status bit7 (READY); if bit1 (16COLLS) clear and timed out -> give up. Then Turbo: another 300000-poll loop (nothing to check on Turbo; non-Turbo polls BMAP bit 29); then if control reg `$02106006` bit6 (ENCTRL_BADTPE, no TP link) -> `$02106004 &= ~4`, delay 500 ms, `enet_reg_poll($02106002)`, and retry from the CSR reset with TPE re-enabled.
* Exit: wait for TX READY again (prints "en_write: tx not ready\n" on timeout), then `$02106004 &= ~$80` (transmitter off). No return value.

### `sub_010095b2` enet_close (): `$02000110 <- $00100000`, `$02000150 <- $00100000` (DMA_RESET), `$02106006 <- $80`. Returns 0.

## KMS keyboard and screen console ($01009860..$01009e98)

KMS registers (kms.c): `$0200E001` KM status/control (bit4 NMI_RECEIVED, bit6 KM_RECEIVED),
`$0200E002` TX status/control (bit1 KMS_ENABLE, bit0 TX_LOOP), `$0200E003` command, `$0200E004` data.
`sub_0100a520(cmd, data)` enables KMS (`$0200E002 |= 2`, sets mg+$170 bit7) then writes
