# ROM range $01004000 .. $01005FFF (Rev 3.3 v74)

Listing lines ~6400..9625. Routines that start in this range. Read together with
`names/01004000.py`.

Conventions used below:

* `mg` = monitor globals struct; `sub_01000686` returns it (`vbr+4`, i.e. the long stored
  at vector 1 of the exception table which is `mg+$400`). `sub_01000690` returns `vbr` itself.
* `mg+$194 == $139` means **non-Turbo I/O** (BMAP / old DMA). It is set at `$01000d32`
  (machine type 0) and `$01000d3c` (types 1..3, also sets `mg+$3b2` = BMAP `$020C0000`).
  For every Turbo type (4..$B, including our Turbo Color type 5) `mg+$194` stays 0.
  Name suggestion: `mg_io_style` (or keep `$139` as the "NeXT (non-Turbo) DMA chip" tag).
* `mg+$3a8` = machine type. `mg+$16..$35` = NVRAM copy; `mg+$16+$e` = NVRAM byte 14 = POT
  byte (rtcnvram.c: `POT_ON` $01, `EXTENDED_POT` $02, `LOOP_POT` $04, `VERBOSE_POT` $08,
  `TEST_DRAM_POT` $10, `BOOT_POT` $20, `TEST_MONITOR_POT` $40). NVRAM bytes 15/16 = oldest /
  most recent self-test error code.
* `mg+$19c` = pointer to interrupt status `$02007000`, `mg+$1a0` = pointer to interrupt mask
  `$02007800`, `mg+$170` = word of console flags (bit 3 = "alert on screen", bit 7 = KMS TX
  enabled, used by `sub_0100a520`).
* Helper routines outside the range that these tests call (identified from their code):
  `sub_01008936(us)` = delay in microseconds (busy-waits on the event counter `$0211A000`
  through `sub_0100889c`/`sub_01008924`); `sub_01007dd6(n)` = allocate n bytes from
  `mg+$ec` downward, zeroed (`mg_alloc_brk`); `sub_01007ffc(p,n)` = bzero; `sub_01007ec8(s,d,n)`
  = bcopy; `sub_01007e16(a,b,n)` = bcmp (0 = equal); `sub_01007772` = printf; `sub_0100785c` =
  printf to the alert/console (used for error text); `sub_0100a1a8` = poll the power button
  (interrupt status bit 2 `INT_POWER`, asks "really power down?"), called between every test;
  `sub_01008184` = console "key pressed?" test (returns non-zero when a key is down);
  `sub_010087cc(reg)` = RTC/NVRAM register read (returns byte), `sub_010086e8(reg,val)` = RTC
  register write (bit-bangs SCR2 bits `RTCE`/`RTCLK`/`RTDATA`); `sub_0100861c(buf)` = read the
  32 NVRAM bytes into buf and verify the checksum (0 = ok, -1 = bad); `sub_01008400` = RTC init
  (reads reg $30, writes reg $31); `sub_01008e5e(netif)` = Ethernet driver init (returns
  pointer to station address or 0); `sub_0100928a(buf,len,0)` = Ethernet transmit ("en_write");
  `sub_01009116(buf,len)` = Ethernet receive poll (non-zero = packet received);
  `sub_010095b2` = Ethernet stop (both DMA CSRs = `DMA_RESET`, `EN_Reset` = $80);
  `sub_0100a520(cmd,data)` = KMS command send (enables KMS TX once, writes `$0200E003`/`$0200E004`).

DMA CSR command bits (Previous `dma.c` 77-110 and 1098-1110): `DMA_SETENABLE` $00010000,
`DMA_SETSUPDATE` $00020000, `DMA_DEV2M` $00040000, `DMA_CLRCOMPLETE` $00080000,
`DMA_RESET` $00100000, `DMA_INITBUF` $00200000 (non-Turbo), Turbo-only: `DMA_SETCOMPLETE`
$00200000, `DMA_FLUSH` $00400000, `DMA_BUFRESET` $00800000. Status bits read back:
`DMA_ENABLE` $01000000, `DMA_SUPDATE` $02000000, `DMA_COMPLETE` $08000000, `DMA_BUSEXC`
$10000000.

**Every DMA reset in this range is written as**
`(mg+$194 == $139 ? $00200000 : $00800000) | $00100000`, i.e. `DMA_RESET|DMA_INITBUF` on
non-Turbo and `DMA_RESET|DMA_BUFRESET` on Turbo. This idiom appears at `$0100487e`,
`$01004ff4`, `$0100506e`, `$01005150`, `$010051e4`, `$0100527c`, `$010052a4`, `$01005640`,
`$010058a6`. The Turbo Color core must accept `$00900000` as a channel reset.

## LED / halt path

### `led_blink_halt` `sub_010040e8` / `led_blink_loop` `loc_010040ec`

* C entry `sub_010040e8(n)`: `a0 = $4(a7)` then falls into the asm loop. Asm entry (used from
  the pre-stack reset code with `jmp`/`bra`) takes the count in `a0`.
* Loop: `d1 = n-1`; for each blink: `SCR2 ($0200D000) |= 1` (`SCR2_LED` on), delay
  (`$10 x $FFFE` `dbeq` iterations), `SCR2 &= ~1`, same delay; after `n` blinks a long delay
  (`$80 x $FFFE`) then `jmp loc_010040ec` -> repeats forever. Never returns.
* Callers and their blink counts (a0): `$01000178` = 6 (unknown machine type at reset),
  `$010003fa` = 1 (ROM header CRC mismatch), `$01000428` = 2 (ROM body CRC mismatch),
  `$01003d30` = 3 (from the early memory test `loc_01003d26`), `$01003eac` = 5 (from
  `$01003e0e` memory loop), `$01005d1c` = 4 (RTC RAM walking-1 failure, see
  `nvram_check_or_rtc_ramtest`). Only 7 (unused here) is missing from 1..6.
* Writes are `ori.l`/`andi.l` on the whole 32-bit SCR2, so the core must support long RMW on
  `$0200D000` with bit 0 (byte 3 bit 0) = LED.

### `led_on` `sub_010040c4` / `led_off` `sub_010040d6`

`ori.l #1,($0200D000,a0)` / `andi.l #$FFFFFFFE,...` with `a0 = $4(a7)` (a displacement,
0 from the two callers `$01003232` / `$010032cc` in the memory test). Same LED bit.

### `sub_01004072` `tmc_parity_init_range(start, end)` -- Turbo only

For every long from `a0 = start` to `a1 = end` (exclusive): read the long, `TMC ctrl
$02200010 |= $400` (bit 10 = parity enable), `nop`, write the long back, `TMC ctrl &= ~$400`,
`nop`. After the loop sets bit 10 again and leaves it set. Called from `$010038aa` (memory
sizing/test). Purpose: rewrite RAM with parity generation on so the parity bits become valid,
then keep parity checking enabled. Core implication: TMC control bit 10 must be writable and
reads must not fault before this is done.

### Cache helpers

* `sub_010040a8` `cpusha dc` (pointer-table entries `$0101b094`, `$0101b0b0`).
* `sub_010040ac(cacr)`: `cinva bc`, returns old CACR in d0, loads new CACR from `$4(a7)`.
* `sub_010040bc`: `d0 = cacr; cpusha dc`.

### `crc32` (`loc_0100418e`, `sub_010041e2`)

`loc_0100418e`: `SCR2 |= 1` (LED on during CRC), `d0 = $FFFFFFFF`, for `d3` bytes at `a1`
bit-serial CRC-32 with polynomial `$04C11DB7` (MSB first), `not.l d0`, then bit-reverses the
32-bit result (`roxl/roxr` loop), `SCR2 &= ~1`, `jmp (a0)`. Result is the standard
reflected CRC-32. `sub_010041e2(buf,len)` is the C wrapper (a1 = buf, d3 = len, a0 =
`sub_010041fe` continuation which restores registers and returns d0). No direct C caller
found (callers of the ROM checksum are the reset path, which uses the asm entry).

## Boot picture drawing (`$01004208..$010047aa`) -- not POST

These draw the 2-bit-per-pixel NeXT logo/animation images onto the framebuffer.
mg fields proven by this code:

| field | meaning |
|---|---|
| `mg+$324` | pixels per 32-bit long: 1 (32 bpp), 2 (16 bpp), 4 (8 bpp), $10 (2 bpp). Selects the span routine. |
| `mg+$330` | framebuffer bytes per row |
| `mg+$33c` | 4-entry lookup table (longs) translating a 2-bit source pixel to a framebuffer pixel; the byte at +3 is used for 8 bpp, the word at +2 for 16 bpp, the long for 32 bpp, low 2 bits for 2 bpp. |
| `mg+$348` | when == -1 the 'U' image is copied raw (no lookup) |
| `mg+$368` | current draw framebuffer pointer |
| `mg+$374` | visible framebuffer pointer (swapped into `$368` by `vid_draw_image_onscreen` with SR=$2700) |
| `mg+$3a0` | draw nesting counter (`sub_0100b2b2`/`sub_0100b2f4` bracket every draw; when it goes 0->1 and `mg+$34c` equals `mg+$6` (slot id) `sub_0100b8d8` is called, probably cursor hide) |

* `vid_draw_image(x, y, img)` `sub_01004440`: `img+0` = type byte, `img+4` = width (pixels),
  `img+8` = height, `img+$c` = data. Destination pixel offset = `x + y*rowbytes`. Type `'B'`
  ($42) -> `vid_draw_rle_image` (rows of `(value, count)` byte pairs, `count` pixels each);
  `'U'` ($55) -> `vid_draw_raw_image` (packed 2 bpp rows, 4 pixels per byte, expanded through
  the lookup table for every depth; raw byte copy at 2 bpp or when `mg+$348 == -1`);
  `'S'` ($53) -> `vid_draw_tbl_rle_image` (first byte n, then n `(value,count)` pairs into two
  256-byte tables on the stack, then one index byte per run). Returns 0.
* `vid_span_2bpp/8bpp/16bpp/32bpp(dst_off*, value, count)`: write `count` pixels of 2-bit
  `value` (4 pixels per source byte are unpacked from `value`) at the pixel offset pointed to
  by `dst_off`, advance `*dst_off` by `count*4`. Called through the function pointer chosen in
  `vid_draw_image`. Turbo Color uses `mg+$324 == 2` (16 bpp), i.e. `vid_span_16bpp` and word
  writes to VRAM at `$0C000000+`.
* `vid_draw_image_onscreen` `sub_010043fc` (called from `$010077d0`): same args, but forces
  the visible framebuffer with interrupts disabled.

## POST framework

### `post_run_all` `sub_01005a46` (called from `$010017e8` in `sub_01000ec6`)

Reads the NVRAM POT byte (`mg+$16+$e`):

| bit | local | effect |
|---|---|---|
| $01 `POT_ON` | | if clear return 0 immediately (no tests) |
| $08 `VERBOSE_POT` | d2 | print "Testing the FPU", ", SCC", ", SCSI", ", Enet", ", ECC", ", RTC", ", Timer", ", Event Counter", ", Sound Out" before each test |
| $04 `LOOP_POT` | d5 | after a pass: print "\n\nPress and hold any key to exit self test", poll the keyboard 10 x 400 ms, then `reset_entry` (restart the whole ROM) unless a key is held |
| $02 `EXTENDED_POT` | d4 | run "Extended Self Test" = `post_ext_scsi_test` |
| $40 `TEST_MONITOR_POT` | d3 | run `post_snd_out_test` twice (silence, then tone) |

Order and error code mapping (d0 returned to the caller; the caller stores it in NVRAM byte 16,
moves the old one to byte 15, writes NVRAM back with `sub_0100866c`, prints
"System test failed.  Error code %x.\n\n" and shows the "System\ntest\nfailed" alert via
`sub_01002462`; on 0 it prints "\nSystem test passed.\n"):

| order | test | routine | code = (d0 & $F) \| |
|---|---|---|---|
| 1 | FPU | `post_fpu_test` `sub_0100483e` | `$40` (1 regs, 2 formats, 3 arithmetic) |
| 2 | SCC | `post_scc_test` `$010048a6` | `$50` (1..7) |
| 3 | SCSI | `post_scsi_test` `$01004a2a` | `$60` (1..3) via `loc_01005c68` |
| 4 | Enet | `post_enet_test` `sub_01004bf0` | `$70` (1..7) |
| 5 | ECC (optical disk) | `post_ecc_test` `sub_01004f12` | `$80` (1..6) -- **only machine type 0 or 2 (cubes); skipped on every station incl. Turbo Color** |
| 6 | RTC | `post_rtc_test` `$010052d0` | `$90` (1) |
| 7 | Timer | `post_timer_test` `$0100534e` | `$C0` (2, 3) |
| 8 | Event counter | `post_evcnt_test` `$01005440` | `$D0` (1..3) |
| 9 | Sound out (if `TEST_MONITOR_POT`) | `post_snd_out_test(1)` then `(0)` | `$E0` (1, 2) |
| 10 | Extended SCSI (if `EXTENDED_POT`) | `post_ext_scsi_test` `$01004ada` | `$60` (4..8) |

Codes `$A0` and `$B0` are not produced here (memory tests elsewhere use the alert texts
"Main Memory ... Test Failed"). Between tests `sub_0100a1a8` polls the power switch. All tests
run on Turbo Color except ECC; none of the tests in this range checks the machine type
except through `mg+$194` (DMA reset bits, SCR2 timer bit, KMS underrun handling).

### `nvram_check_or_rtc_ramtest` `sub_01005cd2` (called from reset `$01000556`)

No arguments. `sub_0100861c(local 32-byte buffer)`: if it returns 0 (checksum OK) the
result is `d0 = NVRAM byte 14 & $10` = `TEST_DRAM_POT` (0 or $10) -- the reset code keeps
this in d2 to decide whether to run the DRAM test later. If the checksum is bad it runs a
walking-one test on the 32 RTC RAM registers: for reg 0..31, for bit 1,2,4..$80: write via
`sub_010086e8(reg, bit)`, read back with `sub_010087cc(reg)`, on mismatch call
`led_blink_halt(4)` (never returns). If all pass returns 1 (meaning "NVRAM invalid but RTC
RAM works", the caller then re-initialises NVRAM). So: **d0 = 0 -> NVRAM valid and no DRAM
test wanted, $10 -> valid and DRAM test wanted, 1 -> NVRAM checksum bad.** For the core:
RTC RAM registers 0..31 must be fully read/write.

## FPU tests (`post_fpu_test` `sub_0100483e`, `$01005d44..$01005e9c`)

These are **not** cache tests: they exercise the 68040 FPU and run on every machine type.

* `fpu_test_regs` `sub_01005d44`: for patterns d1 = 0, -1 (`$FFFFFFFF`), 1, -1, `$55555555`,
  `$99999999`, `$88888888`, `$77777777` calls `fpu_test_regs_pattern` `sub_01005d82`: pushes
  8 x (d1,d2,d3) (96 bytes = 8 extended values), `fmovem (a7)+,fp0-fp7`, `fmovem fp0-fp7,-(a7)`,
  pops and compares (the mantissa words exactly, the exponent word only in the upper 16 bits),
  then rotates the 96-bit pattern left by one bit, 256 times. `d0` accumulates `sne` results.
* `fpu_test_formats` `sub_01005dd2`: for the 1024 integers `$8000..$83FF`: `fmove.l d3,fp1`,
  round trips through `fmove.l/.s/.d/.x` to the stack, `fmove.l fp1,d4`, compare.
* `fpu_test_arith` `sub_01005e1c`: `fp0 = $8000`; 1024 times: fp1 = fp0 + 1023.0 (fadd.s d2)
  + 5 + 7 + 9 (byte/word/long immediates), `fnop`, `fsave/frestore`, subtract the same
  four, fp2 = fp1; fp2 = sqrt(((fp2*fp2)/fp1)^2) = fp1; `fcmp fp0,fp2`; `fsne d1`; fp0 += 1.
* Error code: 1, 2, 3 for the three sub-tests -> POST code `$41..$43`.

## `post_scc_test` `$010048a6` -- Z8530 internal loopback (all machine types)

Registers (device mirror): `a4 = $02118000` = SCC channel B control, `$02118001` = channel A
control, `$02118002` = B data, `$02118003` = A data. `post_delay_9us` between every access.

Sequence (all byte writes):

1. read A control (reset the register pointer); write A control `$09` (select WR9), write
   A control `$CA` (WR9 = force hardware reset `$C0` | MIE `$08` | NV `$02`).
2. write the 20-byte table at `$010195f4` to A control, one byte per 9 us:
   `04 44  0B 50  0E 10  0C 0A  0D 00  0E 11  0A 00  03 C1  05 EA  0F 00`
   = WR4 `$44` (x16 clock, 1 stop bit, no parity), WR11 `$50` (Rx and Tx clock = BRG),
   WR14 `$10` (local loopback), WR12 `$0A`, WR13 `$00` (BRG time constant 10),
   WR14 `$11` (loopback + BRG enable), WR10 `$00` (NRZ), WR3 `$C1` (Rx 8 bits, Rx enable),
   WR5 `$EA` (DTR, Tx 8 bits, Tx enable, RTS), WR15 `$00` (no external ints).
3. read B control, write the same table to B control, read A control.
4. Channel A: up to 5000 times: write `0` to A control (select RR0), read RR0, until bit 2
   (Tx buffer empty) is set -> else **error 1**. Write `$40` to A data. Poll RR0 bit 0 (Rx
   char available) up to 5000 times -> else **error 2**. Read A data, must be `$40` -> else
   **error 3**.
5. Channel B: same via B control/data: **error 5** (tx never empty), **error 6** (no rx),
   **error 7** (data != `$40`). Error 4 is unused. Returns 0 on success.

Core requirement: an SCC model where local loopback (WR14 bit 4) returns transmitted
bytes with RR0 bit 0 set, RR0 bit 2 idle high, and the pointer-register write protocol.

## `post_scsi_test` `$01004a2a` -- NCR 53C90 FIFO (all machine types)

`a3 = $02114000` (ESP base, device mirror).

1. `$02114108` (floppy control) `&= ~$40` (clears `CTRL_82077`).
2. `$02114020` (ESP_DMA_CTRL) = `$02` (`ESPCTRL_RESET`, hard reset ESP), delay 10 us,
   = `$00`, delay 10 us.
3. ESP command (`+3`) = `$02` (chip reset), = `$00` (NOP).
4. FIFO (`+2`) writes `0,1,2,3,4`; FIFO flags (`+7`) `& $1F` must be 5 -> else **error 1**.
5. read FIFO: first byte must be 0 and the next must be 1 -> else **error 2**.
6. FIFO flags `& $1F` must be 3 -> else **error 3**. Returns 0.

## `post_ext_scsi_test` `$01004ada` -- extended (only with `EXTENDED_POT`)

1. ESP_DMA_CTRL = `$02`, delay 10, = `$00`, delay 10; command `$02` (reset), `$00` (NOP),
   `$01` (flush FIFO), delay 10; FIFO flags `& $1F` must be 0 -> **error 4**.
2. transfer count low (`+0`) = `$55`, high (`+1`) = `$55`, command `$80` (DMA NOP = load
   transfer counter); read back high<<8|low must be `$5555` -> **error 5**; same with `$AA`
   -> **error 6**.
3. configuration register (`+8`): write 0..255 and read back each -> **error 7**; then 0.
4. read interrupt status (`+5`) to clear; command (`+3`) = `$FF` (illegal); delay 10 us;
   interrupt status bit 6 (`INTR_ILL`) must be **set** -> else **error 8**.
5. command `$02` (reset), `$00`. Returns 0.

Core requirement: transfer-count registers must be loadable by a DMA-NOP command and readable
back; the config register must be fully read/write; an illegal command must raise
`INTR_ILL` within 10 us.

## `post_enet_test` `sub_01004bf0` -- AT&T 7213 loopback (all machine types, Turbo path marked)

Locals: `-$6(a6)` = broadcast address copied from `dat_01019608` (6 x `$FF`); `-$2e(a6)` =
$28-byte network interface descriptor zeroed by bzero, then `+0 = 2`, `+8 = 0`, `+$c = 0`,
`+$10 = sub_0101a95c` (a callback), `+$20 = a3 = alloc($73c)` (driver state; `a3+$1c` = own
station address copy, `a3+$22` = broadcast address). `d5 = sub_01008e5e(netif)` (driver init,
returns pointer to the 6-byte station address) -> 0 = **error 1**. `d3 = 1500` (max frame),
`d4 = alloc(1500)` zeroed.

Loopback enable:
* non-Turbo (`mg+$194 == $139`): `EN_TX_Mode $02106004 = $02`, delay 9 us, `= $00`, then BMAP
  `+$30 |= $90000000`, BMAP `+$34 &= $6FFFFFFF` (BMAP transceiver/loopback select).
* **Turbo**: `EN_TX_Mode &= ~$02`, delay 9 us, `EN_TX_Mode |= $02` (`TXMODE_LOOP` on the
  Turbo 7213 per ethernet.c 583), `EN_TX_Mode &= ~$04` (`TXMODE_TPE` off).

Then `delay(100000)` and (code recovered from the mis-decoded bytes):

1. Drain: 1000 polls of `en_read(d4,1500)`; the counter restarts whenever a packet arrives.
   If the last poll still returned a packet -> `en_stop`, **error 2**.
2. Build a frame in `a4 = alloc(1500)`: bytes 0..5 = own address, 6..11 = own address,
   12,13 = `$55,$AA`, 14..1499 = 0,1,2,... (`d0 = 1500-14` bytes). `en_write(a4,1500,0)`.
   `d4 = alloc(1500)`; poll `en_read(d4,1500)` up to 1000 times until a packet arrives ->
   none: `en_stop`, **error 3**. `bcmp(d4,a4,1500)` != 0 -> `en_stop`, **error 4**.
3. Address filter: `$0210600D` (EN_NodeID5, last station-address byte) = own byte 5 + 1;
   `en_write(a4,1500,0)`; `bzero(d4,1500)`; poll 1000 times: if any packet is received
   (counter != 1000) -> `en_stop`, **error 5**.
4. Broadcast: `a4[0..5] = $FF`; `en_write`; `bzero(d4)`; poll up to 1000 -> none: **error 6**;
   `bcmp` mismatch -> **error 7**.
5. Restore: non-Turbo `EN_TX_Mode = $02`; Turbo `EN_TX_Mode &= ~$02` (loopback off);
   `en_stop` (`sub_010095b2`: TX DMA CSR `$02000110` and RX DMA CSR `$02000150` = `DMA_RESET`,
   `EN_Reset $02106006 = $80`). Returns 0.

Note the station address is *not* restored after step 3 (`en_init` rewrites it on the next
open). For the core: the 7213 in loopback must deliver a 1500-byte frame back through the RX
DMA channel, must apply the destination-address filter against `EN_NodeID0..5`, and must
accept broadcast.

## `post_ecc_test` `sub_01004f12` -- MO drive controller ECC (cubes only)

Only run when machine type is 0 or 2 (`$01005b38`). Not applicable to Turbo Color, but the
register writes are recorded here for completeness. `a4 = $02112000` = optical storage
processor (Previous `mo.c`, register offsets: `+4` int status (write `$FC` clears the rw
bits), `+5` int mask, `+6` CSR2, `+7` CSR1 (`FMT_ECC_READ $80`, `FMT_ECC_WRITE $40`), `+$B` ECC
count, `+$10..+$16` flag bytes). DMA: `$02000050` disk channel CSR (`a5+4`), `$02004050`
next/limit (`a5+8`). Buffers (16-byte aligned): `d4` = 1024 bytes filled 0,1,2,..., `a3` =
$510 (1296 = encoded sector) zeroed, `d5` = 1024 zeroed.

1. flags `+$10..+$16 = 35 00 00 33 44 35 33`; CSR2 = 0; int status = `$FC`; int mask = 0;
   CSR2 = `$40` (`MOCSR2_ECC_DIS`).
2. Encode: DMA CSR = RESET(+INITBUF/BUFRESET), 0, 0; next = d4, limit = d4+$400;
   CSR1 = `$40`; DMA CSR = `$00010000` (SETENABLE, mem->dev). Poll int status bit 3
   (`MOINT_ECC_DONE`) every 9 us up to 200000 -> **error 1**.
3. Read back encoded: DMA CSR = RESET|DEV2M(...|$140000), 0, `$40000`; next = a3, limit =
   a3+$510; DMA CSR = `$50000` (SETENABLE|DEV2M); int status = `$FC`; CSR1 = `$80`; poll ->
   **error 2**.
4. Corrupt a3: `[1] = ~[1]`, `[$32] += 1`, `[$64] = ~[$64] + $9C`, `[$C8] += $FF`,
   `[$309] = ~`, `[$37A] += $17`, `[$457] = [$456] + $27`, `[$50A] += $16`,
   `[$215..$234] = (~b % 47) + $25`.
5. Correct: DMA CSR = RESET(...), 0, 0; next = a3, limit = a3+$510; CSR = `$10000`;
   int status = `$FC`; CSR2 = `$60` (`ECC_MODE|ECC_DIS`); CSR1 = `$40`; poll -> **error 3**;
   ECC count (`+$B`) must be `$24` -> **error 4**.
6. Read corrected: DMA CSR = RESET|DEV2M, 0, `$40000`; next = d5, limit = d5+$400; CSR =
   `$50000`; int status = `$FC`; CSR1 = `$80`; poll -> **error 5**. `bcmp(d4,d5,1024)` ->
   **error 6**.
7. DMA CSR = RESET(...), then RESET|DEV2M. Returns 0.

## `post_rtc_test` `$010052d0` (all machine types)

`sub_01008400` (RTC init: read reg `$30`; if bit 7 set -> new clock chip, `sub_0100828c($31,
$80, -1)`; else write reg `$31 = $B0`). Read reg `$30`: bit 7 set -> seconds register `$23`
(new MCS1850-style 32-bit counter, LSB byte) else `$20` (MC68HC68T1 seconds). Read it (d4),
then up to 1101 times: read again, if unchanged `delay(1000)`; if it never changes ->
**error 1** (`$91`). Returns 0. Core: the RTC seconds must advance within ~1.1 s of wall time.

## `post_timer_test` `$0100534e` (all machine types; Turbo differences noted)

Registers: `a0 = $0200D000` SCR2, `a5 = $02116000` hardclock high byte, `a2 = $02116001`
low byte, `a3 = $02116004` hardclock CSR (`HARDCLOCK_ENABLE $80`, `HARDCLOCK_LATCH $40`).

1. non-Turbo only: `SCR2 &= $7FFF` as a long (clears `SCR2_TIMERIPL7`, byte 2 bit 7).
   **Skipped on Turbo.**
2. CSR = `$80` then `$00`.
3. for d2 = 0..$FFFF: low = d2, high = d2>>8, low = d2 again, CSR = `$40` (latch), `nop`,
   read high<<8 | low; must equal d2 -> **error 2** (`$C2`). This is 65536 x 5 accesses.
4. Save vector `$78` (level-6 autovector, from `vbr`) and interrupt mask; vector `$78` =
   `post_timer_isr` (`sub_0100480a` -> `post_timer_ack` reads CSR and writes 0); mask
   (`*(mg+$1a0)`) = `$20000000` (`INT_TIMER` only); saved CSR to local; `SR = $2500`;
   CSR = 0; low = `$FF`, high = `$03`, low = `$E8` (count 1000 us); CSR = `$C0`
   (ENABLE|LATCH); `delay(1100)`; read CSR: if bit 7 still set the ISR did not run ->
   **error 3** (`$C3`).
5. CSR = 0, `SR = $2700`, restore vector and mask. Returns 0.

Core: the hardclock must count in microseconds, latch on CSR bit 6, read back the latched
value, and raise `INT_TIMER` (level 6) when it expires within 1000 us.

## `post_evcnt_test` `$01005440` (all machine types)

Event counter bytes `$0211A000..3` read as `b0 | b1<<16 | b2<<8 | b3` and masked to 20 bits
(the code is a byte-wise read of a 20-bit microsecond counter; note the odd byte order:
byte 1 is shifted by 16, byte 2 by 8 -- the value is treated as `$0211A001..3` big-endian
24-bit, masked to 20 bits, with byte 0 ignored after masking).

1. read, `delay(1)`, read: must differ -> **error 1** (`$D1`).
2. read, `delay(1000)`, read; delta (mod 2^20) must be in `900..1100` us -> else **error 2**
   (`$D2`). (`delay` itself is calibrated from the same counter through `mg+$2f6`.)
3. 100 back-to-back reads into a stack array, 99 deltas averaged (`divs.l`); every delta must
   be within 3 us of the mean (`abs()` at `$01007e0c`) -> else **error 3** (`$D3`).

## Sound output test (only with `TEST_MONITOR_POT`)

### `kms_send_cmd(cmd, data)` `sub_01005606`
Waits while `$0200E002` bit 4 (`TX_CPU`, CPU transmit busy) is set, writes `cmd` byte to
`$0200E003` (KMS_Ctrl_Cmd) and `data` long to `$0200E004` (KMS_Data), `delay(200)`.
Commands used: `$07` = sound out disable, `$0F` = sound out enable (normal sample rate),
`$C7` = analog sound out (one sample long, used in the non-Turbo underrun path).

### `kms_set_volume(chan, base, vol)` `sub_0100567e`
Bit-bangs the volume-control chip through `sub_0100a520($C4, x)` (KMS `CTRLOUT`, each
followed by `delay(200)`): word = `base | chan | vol | $700`; for bit 10 down to 0 send
`base | (bit ? $02000000 : 0)` (data on bit 25) then `base | (bit ? $06000000 : $04000000)`
(clock on bit 26), then `base`, `base | $01000000` (strobe, bit 24), `base`. `chan` = `$40`
(left) or `$80` (right). `base` bit 27 (`$08000000`) = NVRAM byte 3 bit 3 (disable speaker),
bit 28 (`$10000000`) = NVRAM byte 3 bit 2 (lowpass filter) (from `post_snd_out_test`).

### `post_snd_out_test(mode)` `sub_01005758` (pointer table `$01005c20`, `$0100a70a`)
`mode` 1 = 8 KB of silence (bzero), 0 = tone: the 1696-word sine table `dat_01019614` is
written so each table word fills two stereo frames (`(a3,d2*8)`, `+2`, `+4`, `+6`); DMA
length `d2 = $2000` bytes. Buffer at `a3 = $04002000` (fixed DRAM address). Test time
budget `-$24(a6) = 200000` us.

Register sequence:
1. save vector `$78` and int mask; vector `$78` = `post_snd_out_isr` (`sub_0100481a` ->
   `post_snd_out_dma_stop`: sound-out DMA CSR `$02000040` = RESET(+INITBUF/BUFRESET), KMS cmd
   `$07`, `delay(50)`); mask = `$00800000` (`INT_SND_OUT_DMA`); `SR = $2500`.
2. `$0200E000 &= $7F` (clear `SNDOUT_DMA_ENABLE`); KMS cmd `$07` data 0 (sound out off);
   `delay(50)`; `snd_out_clear_underrun_any`.
3. volume left and right = 0 (= maximum) with `kms_set_volume($40, base, 0)`, `($80, base, 0)`.
4. DMA `$02000040` CSR = RESET(...), 0, 0; `$02004040` next = a3; `$02004044` limit =
   a3+$2000; `$02004048` start = a3; `$0200404C` stop = a3+$2000; CSR = `$00010000`
   (SETENABLE); `$0200E000 |= $80` (`SNDOUT_DMA_ENABLE`); `snd_out_clear_underrun_any`; KMS
   cmd `$0F` data 0 (sound out enable).
5. Loop while `d4 > 0` (starts at 8): reads next pointer `(a5)` and `$0200E000` bit 5
   (`SNDOUT_DMA_UNDERRUN`, `bfextu {2:1}`):
   * next == start && underrun: non-Turbo sends KMS `$C7` with the long before `next`
     (analog sample), Turbo just `snd_out_clear_underrun_any`;
   * (second check, same condition) KMS `$C7` with the first buffer word, clear underrun,
     `d4--`;
   * next != start && no underrun: `d5++`, exit when `d5 == 3` (DMA seen running three times);
   * otherwise if `d2 > 49` (d2 is never incremented, so this never fires) set `d6 = 1` and
     print "\nSound Out DMA error!\n".
   The loop structure is odd (probably compiler-folded); in practice it exits after three
   observations of the DMA pointer having moved without underrun, or after 8 underruns.
6. if `d6 == 0`: `delay(200000)` then read DMA CSR; if bit 24 (`DMA_ENABLE`) still set ->
   `d6 = 2` (**error 2**, `$E2`; the 8 KB did not finish in 200 ms + the loop time).
7. `SR = $2700`, restore vector and mask; KMS cmd `$07`; `delay(50)`; restore volumes from
   NVRAM (`bfextu (nvram+2){6:6}` = left, `bfextu (nvram){6:6}` = right, see rtcnvram.c
   bits 4-9 and 20-25); if `mode != 0` `delay(100000)`. Returns d6.

Error 1 (`$E1`) = "Sound Out DMA error!" (unreachable as compiled), error 2 = DMA still
enabled. Core: sound-out DMA must run 8 KB at 44.1 kHz stereo 16-bit (~46 ms) and clear
`DMA_ENABLE` at the limit; the KMS sound status bits 7/5 and the TX-busy bit 4 of
`$0200E002` must behave.

### `snd_out_clear_underrun` `sub_01004142` / `..._wait` `sub_01004156` / `..._any` `sub_010047be`
`sub_01004142` (Turbo): ints off, `bset #5,$0200E000` (writing `SNDOUT_DMA_UNDERRUN` clears
underrun+request, kms.c 646). `sub_01004156` (non-Turbo): if bit 7 (`SNDOUT_DMA_ENABLE`)
is set, wait for `$0200E002` bit 6 (`TX_DMA`) to clear (100 tries then unbounded), then
`bset #5`. `sub_010047be` picks by `mg+$194`.

### Other ISR bodies in this range
* `post_snd_in_dma_reset` `sub_01004872` (frame at `$010047fa`, data-decoded): sound-in DMA
  CSR `$020000C0` = RESET(+INITBUF/BUFRESET). Not referenced by the tests above (probably the
  sound-in overrun handler installed elsewhere; pointer table `$01004800`).
* `post_snd_out_overrun_intr` `sub_010055f2`: prints "Sound Out Over Run Interrupt.\n"
  (frame at `$0100482a`).
* `post_scsi_dma_intr` `sub_01004a16`: prints "SCSI DMA intr?\n" (frame `sub_010047e6`).

## `ncc_cache_data_test` `sub_01005ea0` -- **Nitro (40 MHz NeXTstation Turbo with NCC) only**

Called from `$0100135c` only when `mg+$3ca` (pointer to NCC `$02210000`) is non-zero and d3
(a test-enable flag) is set, after `NCC+0 = $10C`. The Turbo Color target has no NCC
(`mg+$3ca` cleared at `$01000d12` and only set for the Nitro board elsewhere), so this
routine and `sub_01006018` (`ncc_cache_tag_test`, "Secondary Tag ram Test Fail", uses
`$03E00000`) are not exercised on our machine.

* Cache size: `d0 = (NCC+0 & $18) >> 3`; `size = $10000 << d0` (64 KB .. 512 KB).
* Pass 1: write `$AAAAAAAA` to every long of `$03F00000..+size` and read back immediately.
* Pass 2: same with `$55555555`.
* Pass 3: three passes writing the triplet pattern `d3,d2,d4` (initially `$DB6DB6DB,0,0`)
  across the RAM, verify, then "rotate" each word: `x = (x<<1) & (x>>31)` (as compiled this
  zeroes the pattern after the first pass, so passes 2 and 3 test all-zero).
* Finally clears the RAM and returns 0. On mismatch prints "\nCache RAM selftest failure\n",
  "Memory error at location: 0x%x\n", "Value at time of failure: 0x%x\n",
  "Expected: 0x%x     Received: 0x%x\n" and returns the failing address in d0.

## Turbo / Turbo Color summary for the core

* LED = SCR2 bit 0, accessed with 32-bit RMW on `$0200D000`.
* DMA channel resets are written as `$00900000` (`RESET|BUFRESET`); direction bit `$40000`;
  enable `$10000`; completion is detected by `DMA_ENABLE` (bit 24) dropping.
* Sound-out DMA channel `$02004040/44/48/4C`, CSR `$02000040`; sound-in CSR `$020000C0`.
* SCC at the `$02118000` mirror with loopback; ESP at `$02114000`, ESP_DMA_CTRL `$02114020`,
  floppy control `$02114108` bit 6 cleared before the SCSI test.
* Ethernet: `EN_TX_Mode $02106004` bits 1 (loop) and 2 (TPE), `EN_NodeID5 $0210600D`
  writable, `EN_Reset $02106006 = $80`, TX/RX DMA CSRs `$02000110/$02000150`.
* Hardclock `$02116000/1/4`, event counter `$0211A000..3`, RTC through SCR2 byte 2.
* KMS `$0200E000` (sound status bits 7,5), `$0200E002` (TX bit 4, bit 6), `$0200E003/4`
  (command/data); volume chip via CTRLOUT `$C4`.
* Skipped on Turbo Color: ECC/MO test, SCR2 `TIMERIPL7` clear, BMAP loopback registers,
  KMS `$C7` analog-sample path, NCC cache tests.
