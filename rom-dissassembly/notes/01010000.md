# $01010000 .. $01012BFF — optical-disk tail, floppy driver (fd/fc), jump tables

Range summary. The range holds three things:

1. `$01010004..$0101034c`: the tail of the **optical disk (Canon OMD-1)** driver ("od"), whose
   head (`sub_0100f060`, `sub_0100f166`, `sub_0100f244`, `sub_0100f2c8`, `sub_0100f306`) is in the
   previous range. It uses the MO controller at `$02112000` (mirror of `$02012000`, Fujitsu
   MB600310, see Previous `mo.c`). Only machine types 0 and 2 (68030 cube, 040 cube) run it;
   **irrelevant for Turbo Color**.
2. `$010103d0..$01011bee`: the complete **floppy driver**: a volume layer ("fd", NeXT source names
   `fd_intr`, `fvp`) and a controller layer ("fc", `fc_send_cmd`, `fc_specify`) for the Intel 82077AA
   at `$02114100` (mirror of `$02014100`), the external control/status register `$02114108`, the
   SCSI/floppy DMA channel CSR `$02000010` and the ESP DMA control register `$02114020`.
   This applies to every machine type (the ROM only reaches it through the boot device table
   "Floppy disk" and the monitor `e`ject command).
3. `$01011bf0..$01012bff`: **switch jump tables** (all `dc.l`) belonging to routines all over the
   ROM, plus one 256-byte `16*sqrt(i)` ramp.

The network boot / TFTP / "boot devices:" strings named in the assignment are **not** referenced
from this range: `strings.md` puts them in `sub_0100658c`, `sub_01006914`, `sub_01006a44`,
`sub_01006e12` (previous range). The boot device table at `$01013cd4` is only data; its consumer is
`sub_0100658c`.

Helpers from other ranges used here (names are my reading of them, not established):
`sub_01000686` = get mg pointer; `sub_01007772` = printf; `sub_01007ffc` = bzero(p,n);
`sub_01007ec8` = bcopy(src,dst,n); `sub_01007dd6` = alloc(n); `sub_0100743c` = 16-bit checksum;
`sub_01008936` = delay(n) in event-counter ticks (`$0201a000`, microseconds);
`sub_0100a1a8` = monitor idle/abort-key poll; DMA helpers `sub_0100e8cc` dma_init(dcp, csr, bufsize),
`sub_0100e94a` dma_setup(dcp, chain, addr, len, dir), `sub_0100eacc` dma_start(dcp, chain, dir),
`sub_0100eb90` dma_stop(dcp), `sub_0100ea5a` dma_cleanup(dcp, resid).
Direction constant `$40000` = `DMA_DEV2M` (dma.c), 0 = mem->dev.

## A. Optical disk tail (machine types 0 and 2 only)

The od struct is `mg+$18e` (allocated with size `$210c` by `sub_0100f166`), `mg+$18a` holds the
MO register base. Fields seen: `+$c` pointer to the drive sub-struct (`+$5c` sector size,
`+$60`, `+$64`), `+$2020` pointer to drive-table entry, `+$20ac` command block (`+0` state bits,
`+$14` byte count, `+$1d` status byte, `+$20` buffer, `+$24` block number), `+$20f4`, `+$20f8`
(= 4149*16 from `dat_0101b370`), `+$2104` flags word (bit 6 = label read once, bit 10 = "no
timeout arg", bit 14 = probe done, bit 15 = open), `+$210a` drive-type index.

### sub_01010004 `od_cmd(op, blkno, buf, len, *status, x, x, x, timeout)` (166 bytes)
Called from `sub_0100f2c8` (device-switch read, op 2), `od_read_label` (ops `$F0`, 2),
`od_eject` (op `$F1`). Only the low word of `op` is used (`$a(a6)`).
* cmd block `a2 = od+$20ac`: `(a2) = 9`, `od+$2106 = op`, if `$24(a6)==0` then `od+$2104 |= $400`,
  `$24(a2) = blkno`, `$14(a2) = roundup(len, secsize)`, `$20(a2) = buf`; `sub_0100f306(cmd, timeout)`.
* Polls bit 1 of byte `$3(a2)` (cmd done), calling `sub_0100a1a8` (monitor idle poll) meanwhile.
* Then `od+$2104 &= ~$c00`, `(a2) &= ~8`; if bit 2 of byte `$3(a2)` (error): `*status = $1d(a2)`,
  returns 5; else returns 0.
The labels `sub_01010008` / `sub_0101000c` inside it are **bogus**: the "pointer table entries" at
`01002ff6/01002ffe/01003006` are the bytes `0101 0004` etc. straddling the `move.l #$01010101,d(a4)`
immediates of the memory test at `01002fec`. Same for `sub_010100fa` (`0101a0e6`) and
`sub_01010102` (`0101a97e`, `0101aac2`) which sit inside 16-bit sine/word tables. `sub_01010004`
is one routine `$01010004..$010100a8`.

### sub_010100aa `od_read_label(od)` (366 bytes), called from `sub_0100f166`
* `a5 = str_0101b340 + 48*od->$210a` (drive table, 48-byte entries starting with the name
  "Canon OMD-1"; `+$18..+$24` = up to four candidate label block numbers, -1 terminated:
  0, `$3c460`, -1, -1; `+$28` = sector size 1024 (`$400`) -> `drive->$5c`); `a4 = dat_0101b370 +
  6*index` (`long 4149, word 16` -> `od->$20f8 = 66384`), `drive->$64 = 16`, `drive->$60 = 1`.
* If `od->$2104` bit 6 clear: `od_cmd($F0, 0,0,0, &st, 0,0,0, $80000)`; returns 1 if result 5 and
  status `$3a`/`$3b`, 2 if status `$10`, 3 if status `$14`, and gives up (next block) on any other
  non-zero result.
* Sets `od->$2104 |= $4000`, reads `$1c48` bytes of block `blk` with `od_cmd(2, blk, drive, $1c48,
  &st, ...)`, same status mapping, then `disk_label_check(buf, blk)`; 0 -> return 0.
* After all candidates: returns 4 (caller prints "no valid disk label found").

### sub_01010218 `disk_label_check(label, blkno)` (102 bytes)
Magic at `+0`: `'NeXT'` (v1) or `'dlV2'` -> checksum word at `+$1c46` over `$1c48` bytes;
`'dlV3'` -> checksum at `+$22e` over `$230` bytes. `+4` (dl_label_blkno) must equal `blkno`. Checksum
word is cleared, `sub_0100743c(label, len)` compared with the saved word. Returns 0 ok, -1 bad.
Shared NeXT disklabel format; also usable for SCSI (caller in other range?). Only caller here is
`od_read_label`.

### sub_0101027e `od_eject(ctrl?, unit?)` (144 bytes), callers 0100221e (monitor `e` command),
0100664a (boot code, when device switch is `sub_0101b376` = od), 0100a24a (power-down: eject od
then fd). Machine type must be 0 or 2 and the NVRAM byte `mg+$18` bits{2:4} must not be 6 unless
bit 2 of `mg+$16` or bit 0 of `mg+$19` (NVRAM flags; meaning unverified). Opens the OD with
`sub_0100f244(mg, devinfo{0,1,arg}, 1, 0, arg2)` then `od_cmd($F1, 0,0,0,0,0,0,0,$80000)`. 0 / -1.

### sub_0101030e `od_reset()` (62 bytes), called from `sub_010018d4` at 010018f4 only on the
first (reset) entry. Machine type 0 or 2: `move.b #1,$02112004` (MO_IntStatus, `MOINT_RESET`),
delay 100, `clr.b $02112004`. Not run on Turbo.

### sub_0101034c `od_query_status()` (132 bytes), called from 01002a38 (memory configuration
code, when region base == `$04000000`). Machine type 0 or 2: open OD (`sub_0100f244(mg, devinfo
{0,0,0}, 1,1,1)`), then `sub_0100ff6a(mg->$18a, mg->$18e, base->$20c, $2000, 9)`; returns 1 if the
result is not -1 and bit 14 is clear, else 0. Purpose uncertain (probably "OD drive present and
not busy" used to decide whether to keep a DMA buffer region).

## B. Floppy driver — data structures

`fcp` (floppy controller struct, `$704` bytes, allocated by `fd_open`, pointer in **mg+$3a4**):

| off | content |
|---|---|
| +0 | long: 82077 register base, `$02114100` |
| +4 | long flags: bit 3 (`$8`) interrupt-wait timed out, bit 10 (`$400`) controller hung / needs reset, bit 14 (`$4000`) DMA transfer active, bit 15 (`$8000`) DMA direction device->memory (read), bit 16 (`$10000`) DMA error (read from dma layer), bit 17 (`$20000`) set by fc_init |
| +8 | long: current command block (fvp+8) |
| +$c | long: current fvp |
| +$10 | byte: shadow of the external control register `$02114108` |
| +$12 | DMA channel struct `dcp` (`$f4` bytes): dcp+$1c = fcp+$2e = CSR pointer `$02000010`; dcp+$20 direction; dcp+$e4 aligned DMA buffer |
| +$106 | DMA chain entry list (10 x `$1c`: next, start, end, ...) |
| +$21e | long: pointer to ESP DMA control register `$02114020` |
| +$222 | long: density for which SPECIFY/data rate was last programmed |
| +$22a | `fvp` (floppy volume struct, see below) |
| +$284 | long: bit 0 cleared by fc_init |
| +$2fb.. | DMA sector buffer; 16-byte aligned start stored at +$6fc |
| +$700 | long: "quiet" flag (suppress error prints) |

`fvp` (= fcp+$22a):

| off | content |
|---|---|
| +0 | long: density (1 = 720K DD, 2 = 1.44M HD, 3 = 2.88M ED) |
| +4 | long: unit number |
| +8 | command block, `$52` bytes (layout below) |
| +$5a | long 1 |
| +$5e | long state: 0 done, 1 start, 2 transfer running, 3 recalibrating |
| +$62 | long density copy; +$65 byte: drive select (0) |
| +$66 | long: fcp |
| +$6a | long flags: bit 0 = 1, bit 1 = motor on |
| +$6e | long: drive type index into `str_0101b3d4` table ("Sony MPX-111N", 60-byte entries) |
| +$72 | long current sector (LBA); +$76 bytes remaining; +$7a buffer pointer |
| +$7e/+$82/+$86 | sector / byte count / buffer of the transfer in flight (for retry) |
| +$8a | long retry count; +$8e recalibrate count |
| +$92 | long flags: bit 0 = read (1) / write (0), bit 1 = raw command (execute cmd block as given) |
| +$96 | geometry: +$96 media id, +$9a byte heads (2), +$9c long cylinders (80), +$a2 word density, +$a4 flags (bit 0 geometry valid), +$a8 density key, +$ac capacity bytes, +$b0 word GPL byte, +$b2 long MFM (1), +$b6 sector size, +$ba sectors/track, +$be total sectors |

Command block (`fvp+8`, passed to the fc layer):

| off | content |
|---|---|
| +0 | byte: density code |
| +2 | long: timeout in ms |
| +6 | long: type: 1 = send 82077 command, 2 = eject, 3 = motor on, 4 = motor off, 5 = media status only |
| +$a..+$12 | 82077 command bytes (opcode in +$a bits 4:0) |
| +$1a | long: number of command bytes |
| +$1e | long: DMA address; +$22 long: byte count (0 = no DMA) |
| +$26.. | result bytes (ST0 ST1 ST2 C H R N) |
| +$36 | long: expected result bytes |
| +$3a | long flags: bit 1 = read (device->memory DMA); clear = write |
| +$3e | long status: 0 ok, -1 pending, 1 timeout, 3 DMA error, 4 bad parameter/opcode, 5 no drive, 8 R/W error, 9 seek/recal error, `$a` phase error, `$12` no result bytes |
| +$42 | cmd bytes sent; +$46 bytes transferred; +$4a result bytes received |
| +$4e | byte: bits 7:6 media id (from ext status), bit 5 motor on |
| +$50 | byte: drive select (0..3) |

Density tables (data, 14-byte entries `{long key, long a, word b, long c}`, key 0 terminates):

* `dat_0101b410` (media id -> geometry): key 3 -> heads 2, cyl 80, density 1; key 2 -> 2, 80, density 2;
  key 1 -> 2, 80, density 3. Media id 3 = 720K, 2 = 1.44M, 1 = 2.88M (matches Previous `MEDIA_ID_*`).
* `dat_0101b448` (density -> parameters): 1 -> capacity `$b4000` (737280), GPL word `$0800`, MFM 1;
  2 -> `$168000` (1474560), `$1000`, 1; 3 -> `$2d0000` (2949120), `$2000`, 1; terminator entry 0 -> `$b4000`, `$3000`, 1.
  Only the high byte of the GPL word is used as the R/W gap length (8, $10, $20).

Drive table `str_0101b3d4` "Sony MPX-111N", 60 (`$3c`) bytes per entry, index `fvp+$6e` (always 0):
`+$28 = $400`, `+$2c = $10000`, `+$30` step rate = 3, `+$34` head unload = `$10`, `+$38` head load = `$20`
(longs at 0101b404/08/0c). With fc_specify this gives SPECIFY bytes `03 D8 04` for 500 kbps,
`03 E4 02` for 250 kbps and `03 A0 08` for 1 Mbps (HUT 16 overflows the 4-bit field to 0).

## C. Floppy volume layer ("fd")

### sub_01010562 `fd_open(mg, devinfo, noprobe, quiet)` (286 bytes) — device switch entry 0 of table `0101b3bc`
Table `0101b3bc`: `{fd_open, fd_close, fd_read, fd_write_nop, fd_round_to_sectors, 1}` — the "Floppy
disk" boot device (compare `0101b376` for the OD: `{sub_0100f244, sub_0100f2c0, sub_0100f2c8,
sub_0100f2fe, sub_0100f22e, 1}`). Called from `fd_eject` and (through the table) the boot code.
* `devinfo`: `+0` ctrl (must be 1, else unit = 0), `+8` unit, `+$14` <- sector size, `+$18` <- total sectors.
* Allocates fcp (`sub_01007dd6($704)`), stores in `mg+$3a4`; `fcp+$6fc = (fcp+$2fb) & ~15`; `fcp+$700 = quiet`.
* `fd_vol_init(fvp, unit)`, `fvp+0 = fvp+$62 = unit`(!), `fvp+$66 = fcp`, `fvp+$6a = 1`.
* `fc_init(fcp, $02114100)`; non-zero -> return -1.
* `fvp+$a4 &= ~1`; `fd_probe_media(fcp, noprobe)`; if it fails and `quiet` -> return code silently.
* Messages by code: 1 "No Floppy Disk Drive\n", 3 "No Floppy Disk Present\n", 4 "Floppy Disk not
  Formatted\n", other "Unknown Floppy Disk error (%d)\n"; returns the code.
* Code 0: if `noprobe==0` and geometry not valid (`fvp+$a7` bit 0): "Floppy Disk not Initialized\n",
  `fd_close`, return 4. Else `devinfo+$14 = secsize`, `+$18 = nsectors`, return 0.

### sub_010103d0 `fd_probe_media(fcp, noprobe)` (402 bytes)
* `fvp+$a8 = 1`, `fvp+$a4 &= ~1`; up to 2 x `fd_recalibrate(fvp)`; both fail -> "fd: RECALIBRATE
  FAILED\n" (unless quiet), code 1.
* `fd_sense_media(fvp, &w)`; error -> "fd: CONTROLLER I/O ERROR\n", code 1. Media id = bits 7:6 of
  the returned byte; 0 -> code 3 (no disk). Else geometry entry copied from `dat_0101b410`.
* `noprobe != 0`: `fd_set_density(fvp, 3)`, `fd_set_geometry(fvp, 512)`, return 0 (used by eject).
* Otherwise autodetect: `fvp+$a4 |= 1`, `fvp+$b2 = 1` (MFM), for density 3,2,1: `fd_set_density`,
  for secsize 512 then 1024: `fd_set_geometry`, then two test reads `fd_probe_read(fvp, sector, 1,
  fcp->$6fc, 1)` at sector 0 and sector `spt+1`; first success -> return 0. Between densities a
  `fd_recalibrate`; failure -> "RECALIBRATE FAILED\n", code 1. Nothing readable -> code 4, after
  `fd_simple_cmd(fvp, 4)` (motor off), which is also issued for codes 1 and 3.

### sub_01010688 `fd_read(mg, x, sector, buf, len)` — device switch read
`fd_setup_io(fvp, sector = $10(a6), nsectors = len / secsize, buf = $14(a6), read = 1)`; returns
`len - fvp->$76` (bytes done) or -1.

### sub_010106de `fd_round_to_sectors(mg, devinfo, len, x)` = `ceil(len / devinfo->$14) * x`.
### sub_01010680 `fd_close`, sub_010106d6 `fd_write_nop`: empty.

### sub_01010700 `fd_eject(unit)` (90 bytes), callers 01002200 (monitor `e f` — the byte compared is
`'f'`), 0100a252 (power down, after `od_eject`). `fd_open(mg, {1, unit, 0}, 1, 1)` then
`fd_simple_cmd(fvp, 2)` (EJECT). Returns 0 / -1.

### sub_0101075a `fd_raw_cmd(fvp, cmdblk)` (98 bytes)
`bcopy(cmdblk -> fvp+8, $52)`, `fvp+$92 |= 2`, `fd_run_io(fvp)`; result -1 if it returned non-zero
or `cmd+$46` (bytes moved) non-zero; `bcopy(fvp+8 -> cmdblk)`; returns the result.

### sub_010107bc `fd_run_io(fvp)` (82 bytes)
If raw flag (`fvp+$95` bit 1): `fvp+$76 = 0`; else `fd_start_transfer(fvp)`, `fvp+$8a = 2` retries,
`fvp+$8e = 1` recalibrate. `fvp+$5e = 1`; `while (fvp+$5e) fc_start(fvp)`; returns `fvp+$46`
(bytes moved of the last command).

### sub_0101080e `fd_intr(fvp)` (144 bytes) — called by `fc_start` after each command
Raw mode: state = 0, done. Otherwise, if `cmd+$46 != 0`: for READ/WRITE (opcode 6/5) round the
byte count down to whole sectors; if status 6 (unused here) subtract one sector; `fvp+$76 -= n`,
`fvp+$7a += n`, `fvp+$72 += n/secsize`. Then `switch (cmd+$3e)` via `jt 01012ab4` (0..16):
* 0 -> `fd_intr_ok` (sub_0101089e): state 2 -> 1, 3 -> 2, 1 -> keep; if bytes remain
  `fd_start_transfer` again, else state 0. Any other state: "fd_intr: BOGUS fvp->state", status 4.
* 1, 7..10, 12, 13, 15, 16 -> `fd_intr_error` (sub_010108e2): if state 2: `--retry`; while > 0
  print "RETRY" and re-issue (`fd_start_transfer`); when retries exhausted, once: print
  "RECALIBRATE", retries = 2, build RECALIBRATE, state 3; else "FATAL", state 0. If state != 2
  (a recalibrate just finished): rebuild the transfer, state 2, retry if retries left, else FATAL.
* 2..5, 11, 14 -> `fd_intr_fatal` (loc_01010970): print "FATAL", stop.
`fd_print_error` (sub_01010988) prints "fd%d: Sector %d(d) cmd = %s; status = %d: %s\n" with
unit, sector, "Read" (`$92` bit 0 set) / "W", `cmd+$46`, and the RETRY/RECALIBRATE/FATAL word.

### sub_010109c8 `fd_start_transfer(fvp)` (154 bytes)
Sectors left = ceil(`$76`/secsize); `fd_lba_to_chs(fvp, sector, &chs)`; if the transfer would cross
the end of the track (`R + n > spt+1`) limit it to `(spt - R + 1) * secsize`; saves `$7e/$82/$86`;
`fd_build_rw_cmd(fvp, fvp+8, sector, bytes, buffer, $92 & 1 = read)`.

### sub_01010a62 `fd_build_rw_cmd(fvp, cmd, lba, nbytes, dma, read)` (232 bytes; the descent
decoded `$01010a8a..$01010b49` as a string/data, see section F)
`bzero(cmd+$a, 9)`; `fd_lba_to_chs` fills bytes 2..4; byte 0: MT=0, MFM = `fvp+$b2`, opcode 6
(READ, `read != 0`) or 5 (WRITE, `read == 0`); byte 1: bits 1:0 drive (left 0 here, ORed in by fc_do_command), bit 2 = head
(copied from byte 3); byte 5 N = log2(secsize/128); byte 6 EOT = R + nsectors - 1; byte 7 GPL =
`fvp+$b0` high byte; byte 8 DTL = `$ff`. `cmd+0 = fvp+$ab` (density), timeout 1000 ms, type 1,
9 command bytes, DMA addr/count, 7 result bytes, `cmd+$3a` bit 1 = read (dev->mem).

### sub_01010b4a `fd_setup_io(fvp, sector, nsectors, buf, read)`: `$72 = sector`, `$7a = buf`,
`$76 = nsectors*secsize`, read -> `$92 |= 1` else `&= ~1`; `$92 &= ~2`; `fd_run_io`.
### sub_01010b92 `fd_probe_read(fvp, sector, nsectors, buf, read)`: builds a cmd block on the stack
with `fd_build_rw_cmd` and runs it via `fd_raw_cmd`.
### sub_01010be8 `fd_sense_media(fvp, *word)`: cmd block type 5, timeout 10; `fd_raw_cmd`; `*word =
cmd+$4e`.
### sub_01010c26 `fd_recalibrate(fvp)`: `fd_build_recal_cmd` + `fd_raw_cmd`.
### sub_01010c54 `fd_simple_cmd(fvp, type)`: cmd block type `type`, timeout 10, `fd_raw_cmd`;
returns cmd status (`cmd+$3e`) when the raw call returned 0.
### sub_01010c92 `fd_build_recal_cmd(fvp, cmd)`: bytes `07, 00` (drive bits ORed in later), density,
timeout 1000, type 1, 2 command bytes, no DMA, 2 result bytes (ST0, PCN).
### sub_01010ce0 `fd_lba_to_chs(fvp, lba, *chs)`: C = lba/spt/heads -> byte 2, H = (lba/spt)%heads -> byte 3,
R = lba%spt + 1 -> byte 4.
### sub_01010d36 `fd_vol_init(fvp, unit)`: bzero `$c2`, density 2, unit, `$a8=$a4=0`, `$5a=1`, `$92=0`.
### sub_01010d70 `fd_set_density(fvp, key)`: copies the `dat_0101b448` entry to `fvp+$a8..$b5`; key 0 clears `$a4` bit 0.
### sub_01010dba `fd_set_geometry(fvp, secsize)`: `$b6 = secsize`, `spt = cap/(heads*cyl)/secsize`,
`total = heads*spt*cyl`, `$a4 = ($a4 | 1) & ~2`. Returns 0.

## D. Floppy controller layer ("fc") — register writes in order

82077 registers (byte offsets from `fcp+0 = $02114100`): +0 status A, +1 status B, +2 DOR,
+4 MSR (read) / DSR (write), +5 FIFO, +7 DIR (read) / CCR (write). External control/status
register `$02114108` = fcp base + 8: write bits `$80` eject, `$40` select 82077, `$20` reset;
read bits `$04` no drive (DRV_ID), `$03` media id.

### sub_01010e14 `fc_init(fcp, regbase)` (130 bytes)
1. `fcp+0 = regbase`, `fcp+4 = 0`, `move.b #$40, regbase+8` (**ext control = $40**: select the 82077),
   `fcp+$10 = $40`, `fcp+$222 = 0`, `fcp+$284 &= ~1`.
2. `fc_reset(fcp, NULL)` (see below). Non-zero -> return it.
3. DMA channel: `fcp+$22 = 0`, `fcp+$26 = fcp`, `fcp+$2a = 1`, `fcp+$3e = 0`, `fcp+$2e = $02000010`
   (SCSI-channel TDMA CSR; the floppy shares the SCSI DMA channel), `dma_init(fcp+$12, $1a63)`
   (writes `$00100000` DMA_RESET to the CSR, computes the aligned buffer), `fcp+4 |= $20000`,
   `fcp+$21e = $02114020` (ESP DMA control register). Returns 0.

### sub_010110d8 `fc_reset(fcp, msg)` (170 bytes; `$010110f4..$01011181` mis-decoded, section F)
If `msg`: printf "fc: Controller Reset: %s\n". Then, in order:
`DOR = $00` (reset asserted, motors off), delay 250 (us), `DOR = $04` (RESET_N high, DMAGATE 0,
drive 0), `DSR = $00` (500 kbps, no power-down), `CCR = $00`, `fcp+$10 = $40`, **ext control = $40**,
`fcp+$222 = 0`, `fcp+$3e &= ~$4000`; `fc_configure(fcp, 3)`; if 0 then `fc_specify(fcp, 3,
&drive_table[0])` ("Sony MPX-111N"). Result 0 clears `fcp+4` bit 10, non-zero sets it. Returns result.
Note: the NeXT reset does not use the DSR software-reset bit; it toggles DOR bit 2.

### sub_010112ba `fc_configure(fcp, x)`: cmd bytes `13 00 58 00` (CONFIGURE: EIS=1 implied seek,
EFIFO=0 FIFO enabled, POLL=1 polling disabled, FIFOTHR=8, PRETRK=0), timeout 10, type 1, 4 bytes,
no results; `fc_send_cmd`. (The density argument is unused.)

### sub_0101130e `fc_specify(fcp, density, drvtab)` (382 bytes)
Builds SPECIFY (`03`): byte 1 = SRT<<4 | HUT, byte 2 = HLT<<1 | ND(0). Units depend on density
(data rate): density 1 (250 kbps): SRT = 16 - (t30+1)/2, HUT = t34/4 (0 if > 511), HLT = t38/32
(0 if > 511); density 2 (500 kbps): SRT = 16 - t30, HUT = t34/2 (0 if > 255), HLT = t38/16; density 3
(1 Mbps): SRT = 16 - 2*t30, HUT = t34 (0 if > 127), HLT = t38/8. Other density: printf
"fd: Bogus density (%d) in fc_specify()\n", return 4. The t30/t34/t38 values are the drive table
longs (in ms units of the 500 kbps table). Then **DSR = rate**, **CCR = rate** with rate 2 (250 kbps)
for density 1, 0 (500 kbps) for 2, 3 (1 Mbps) for 3; `fc_send_cmd` (3 bytes, no result, timeout 10);
on success `fcp+$222 = density`.

### sub_01010e96 `fc_start(fvp)` (164 bytes) — runs one command block
`fcp+8 = cmd`, `cmd+$50 = fvp+$65` (drive), status -1, counters 0, `fcp+4 &= ~$14008`.
If `fcp+4` bit 10 (hung): `fc_reset(fcp, NULL)`, status = result, stop on error.
Drive > 3 -> status 5. Else **DOR = (DOR & ~3) | drive | DOR** (selects the drive, keeps motor bits),
then `switch (cmd+6 - 1)` via `jt 01012af8`:
type 1 `fc_do_command`; 2 `fc_eject`, `fvp+0 = 2`; 3 `fc_motor_on`; 4 `fc_motor_off`; 5 nothing
(status 0); other -> 4. Then `fc_read_media_status(fcp, cmd)`, `fvp+$6a` bit 1 = DOR motor bit.
Status 1 (timeout) -> `fc_reset(fcp, NULL)`; status `$a` -> `fc_reset(fcp, "Bad Controller Phase")`;
`fcp+4` bit 10 -> `fc_reset(fcp, "Controller hang")`. Finally `fd_intr(fvp)`.

### sub_0101148c `fc_do_command(fcp, fvp)` (170 bytes)
Opcode = `cmd+$a & $1f`. For opcodes other than 3 (SPECIFY), 19 (CONFIGURE) and 31: OR the drive
number into `cmd+$b` bits 1:0. If `cmd+0` (density) != `fcp+$222`: `fc_configure`, then
`fc_specify(fcp, density, &drive_table[fvp+$6e])`; errors -> status. Then if the drive's DOR motor
bit is already on, or the opcode is not in 2..22: send directly. Else `switch (opcode-2)` via
`jt 01012b0c`: opcodes 2, 5, 6, 7, 9, 10, 12, 13, 15, 17, 22 -> `fc_cmd_motor_on`
(`fc_motor_on`, then **ext status `$02114108` bit 2 set -> status 5 "no drive"**, no command);
opcodes 3, 4, 8, 11, 14, 16, 18..21 -> `fc_cmd_send`. `fc_send_cmd` result -> `cmd+$3e`.

### sub_0101156c `fc_eject(fcp)` (170 bytes)
Motor on if needed; SEEK command (`fc_build_seek_cmd(density, cmd, cyl $4f, head 0)`: bytes
`0F, 00, 4F`, timeout 400, 2 result bytes) via `fc_send_cmd` (a seek to cylinder 79 before eject);
error -> status. Then **ext control |= $80** (`fc_ctrl_set`), **ext control &= ~$80** (`fc_ctrl_clr`),
`fd_wait_intr(fcp, 2000000)` (2 s), `fc_motor_off`, status 0.

### sub_01011670 `fc_motor_on(fcp)`: if `DOR & ($10<<drive)` clear: **DOR |= $10<<drive**,
`fd_wait_intr(fcp, 500000)` (500 ms spin-up; no interrupt expected).
### sub_010116ac `fc_motor_off(fcp)`: **DOR &= ~($10<<drive)**.
### sub_01011230 / sub_0101124e `fc_ctrl_set/clr(fcp, bits)`: update `fcp+$10` shadow and write it to
`$02114108`.
### sub_0101126e `fc_read_media_status(fcp, cmd)`: `cmd+$4e` bit 5 = `DOR & ($10<<drive)`,
bits 7:6 = `ext status & 3` (media id).
### sub_01011182 `fc_send_byte(fcp, b)`: `fc_wait_rqm(fcp, 0)` then `FIFO = b`; returns wait result.
### sub_010111b0 `fc_get_byte(fcp, *p)`: `fc_wait_rqm(fcp, $40)` then `*p = FIFO`.
### sub_010111dc `fc_wait_rqm(fcp, dio)`: polls MSR up to 80000 times for RQM (`$80`); when set,
`MSR & $c0` must equal `$80|dio` else returns `$a` (phase error). Returns 1 only if the loop count is
exactly `$3e80` (16000) — looks like a bug/odd timeout, otherwise 0 even after 80000 polls.

### sub_010116d2 `fc_send_cmd(fcp, cmd)` (554 bytes; `$010118fc..$010119e7` mis-decoded, section F)
1. status -1, counters 0. If `cmd+$22` (byte count) > 0: for READ/WRITE the count must be a
   multiple of 16 and <= 1 MB, else status 4. `fc_dma_reset(fcp)`; direction `$40000` (dev->mem)
   when `cmd+$3a` bit 1 (read) is set, else 0 (mem->dev); `dma_setup(fcp+$12, fcp+$106, addr, len, dir)`,
   `dma_start(fcp+$12, fcp+$106, dir)` (this writes the TDMA CSR: `dir | $100000 | $200000/$800000`,
   next/limit regs at CSR+$4000/+$4004, then `dir | $30000` SETENABLE|SETSUPDATE), d4 = 1.
2. `fcp+$c = cmd`; command phase: for each byte `fc_send_byte`; 0 -> `cmd+$42++`; `$a` -> set hung
   bit 10, exit with `$a`; other -> printf "fc_send_cmd: Error sending command bytes  (%d)\n", set
   bit 10, exit.
3. If DMA: `fcp+4 |= $4000`; read (bit 1): **ESP DMA ctrl `$02114020` |= $08** (`ESPCTRL_DMA_READ`,
   device->memory) and `fcp+4 |= $8000`; write: **ctrl &= ~$08**, `fcp+4 &= ~$8000`.
   Then **ctrl |= $10** (`ESPCTRL_MODE_DMA`). No DMA: `fcp+4 &= ~$4000`.
4. `switch (opcode-3)` via `jt 01012b60` (opcodes 3..31): opcodes 3, 4, 8, 14, 18, 19, 31 (no
   execution phase / no interrupt: SPECIFY, SENSE DRIVE STATUS, SENSE INTERRUPT, DUMPREG,
   PERPENDICULAR, CONFIGURE, 31) go straight to `fc_cmd_result_phase`; all others
   `fd_wait_intr(fcp, timeout_ms*1000)` first (result 1 = timeout).
5. `fc_cmd_result_phase` (sub_0101187e): if DMA active and ctrl bit 4 set: pulse **ctrl |= $04**
   (`ESPCTRL_FLUSH`), delay 5, **ctrl &= ~$04**, delay 5 — 8 times if `mg+$194 == $139`, else once;
   then **ctrl &= ~$10** (leave DMA mode). Wait result 1 -> remember timeout; other non-zero -> exit.
6. Result phase: while `cmd+$4a < cmd+$36`: `fc_get_byte` into `cmd+$26+n`; `$a` with some bytes
   already read -> stop reading, `$a` with none -> exit `$a` ... (see listing: with `$4a==0` it exits
   with `$a`, else breaks); other errors -> printf "fc_send_cmd: Error getting status bytes\n", exit.
7. DMA accounting (if `fcp+4` bit 14): clear it; for WRITE (5/9) with ST1 == `$80` (EN only) bytes
   moved = requested; else `dma_bytes_moved(fcp+$12, fcp+$106)`; clamp to requested; `fcp+4` bit 16
   -> status 3; `dma_cleanup(fcp+$12, 0)`; d4 = 0; `fc_dma_reset(fcp)`.
8. If status still 0: `switch (opcode-5)` via `jt 01012bd4` (opcodes 5..15): 5, 6, 10 (WRITE, READ,
   READ ID) -> `fc_check_rw_result`: no result bytes -> `$12`; OK when ST0 IC = 0, or when
   ST1 == `$80` (end-of-cylinder only), or when IC = `$40` (abnormal), a byte count was requested,
   all requested bytes were moved by DMA and ST1 bit 4 (overrun/underrun) is set (the expected
   termination with external DMA); anything else -> status 8; 7 (RECALIBRATE) ->
   `fc_check_recal_result`: ST0 bit 5 (SE) set, PCN == 0, **status A bit 4 (TRK0_N) low** else 9;
   15 (SEEK) -> `fc_check_seek_result`: SE set and PCN == requested cylinder (`cmd+$c`) else 9.
   Other opcodes: status 0.
9. Exit (`loc_01011a60`): if DMA still set up (d4) `dma_cleanup`; timeout flag -> status 1.

### sub_0101100e `fc_intr(fcp)` (202 bytes) — called by `fd_wait_intr` when INT_PHONE is set
If DMA active: pulse **ESP ctrl |= $04 / &= ~$04** with 5 us delays, once (8x on `mg+$194 == $139`),
then **ctrl &= ~$10**. Poll MSR up to 100 times for RQM; timeout -> `fcp+4 |= $400` (hang).
If DIO = 0 (controller in command phase, i.e. the interrupt came from a SEEK/RECALIBRATE or a
polling/reset interrupt): `fc_send_byte(fcp, 8)` = **SENSE INTERRUPT STATUS**, error -> hang bit.
If DIO = 1: read the FIFO into `cmd+$26` (ST0) and `cmd+$4a++`.

### sub_01011b6c `fd_wait_intr(fcp, us)` (130 bytes)
`fcp+4 &= ~8`; for `us/1000 + 1` iterations: if interrupt status (`mg+$19c` -> `$02007000`) bit 7
(`INT_PHONE`, the floppy interrupt) is set: `fc_intr(fcp)` and stop; else delay 1000. If the loop
ran out: `fcp+4 |= 8`. Returns 1 if bit 3 set (timeout), else 0. This is the only interrupt handling
of the floppy in the ROM: purely polled; the 82077 IRQ line is read through the interrupt status
register bit 7.

### sub_01011a82 `fc_dma_reset(fcp)` (102 bytes)
`dma_setup(fcp+$12, fcp+$106, stackbuf(16-aligned), 16, $40000)`, `dma_start(..., $40000)`, delay 10,
`dma_stop(fcp+$12)` (reads CSR, writes `$00100000` DMA_RESET, saves CSR+$4000). A dummy
16-byte device->memory transfer used to reset the shared SCSI/floppy DMA channel before and after
every real transfer.

### sub_01011ae8 `dma_bytes_moved(dcp, chain)` (132 bytes)
Reads the TDMA "saved next" register `CSR+$4000` (`$02004010`) and walks up to 10 chain entries
(`$1c` bytes: `+0` next, `+4` start, `+8` end, `+$10` flag compared with `$09000000`): the entry
containing the pointer gives bytes moved = sum of previous entries + (ptr - start). Special case:
ptr == end of an entry counts as complete unless the entry is the current one (`dcp+8`). Falls out with
"dma_bytes_moved: DMA buf overflow" if not found.

## G. What the FPGA core must implement for the ROM floppy path (Turbo Color included)

* External control register `$02114108` (mirror of `$02014108`): writes `$40` (select 82077) at
  init and after every controller reset, `$C0` then `$40` for eject. Reads: bits 1:0 media id
  (3 = 720K, 2 = 1.44M, 1 = 2.88M, 0 = none) sampled in `fc_read_media_status` after every command,
  bit 2 = "no drive" checked before every motor-on command.
* 82077 access sequence: DOR `$00` -> 250 us -> `$04`, DSR `$00`, CCR `$00`, CONFIGURE `13 00 58 00`
  (no interrupt, no result), SPECIFY `03 xx xx`, DSR/CCR = rate, then DOR `$04|drive` and
  `$14` (motor 0), RECALIBRATE `07 00` (twice), the interrupt is polled through interrupt status
  bit 7 (`INT_PHONE`) and answered with SENSE INTERRUPT `08` (2 result bytes ST0, PCN; ST0 SE bit,
  PCN 0 and status A TRK0_N low required), then READ DATA `46 hh C H R N EOT GPL FF` (MFM,
  MT = 0, SK = 0, DTL = `$FF`) with 7 result bytes; success requires ST0 IC = 0, or ST1 = `$80`
  (EN only), or IC = `$40` with all bytes delivered by DMA and ST1 bit 4 (OR) set.
* DMA: the floppy uses the SCSI DMA channel (CSR `$02000010`, next/limit at `$02004010/14`, saved
  next read back from `$02004010` for the byte count) and the ESP DMA control register
  `$02114020`: bit 3 direction (set = device->memory for floppy reads, clear for writes), bit 4
  DMA mode, bit 2 flush pulse (1x, or 8x when `mg+$194 == $139`). Transfers are per track, 16-byte
  aligned, <= 1 MB. A dummy 16-byte dev->mem transfer + `DMA_RESET` bracket every real transfer.
* Timing: motor-on 500 ms, eject 2 s, command timeouts 1000 ms (R/W, recal), 400 ms (seek), 10 ms
  (specify/configure), all via the microsecond event counter.
