## Gotchas learned

- **Never touch files.qip, the qsf or RTL while a Quartus flow runs**: an
  edit of files.qip mid-fit made Quartus rewrite NeXT-Color.qsf with every
  sys/ assignment inlined (+247 lines) and the fitter then died.  Restore with
  `git checkout -- NeXT-Color.qsf`.
- A full compile right after `--check` reuses the check's synthesis (smart
  recompilation): the fit is of the sources as they were at the check.
- Git Bash `sed -i` rewrites CRLF files as LF; files.qip is now all LF
  (git stores LF anyway).
- Quartus 17.0 warns "assigned a value but never read" (10036) for signals
  read only inside functions (seqstep, sense_code, ccf_wr): benign, the mono
  core has the same.
- Git Bash heredocs mangle backslashes; use the Edit tool or .py files.
- `scripts/sim_wsl.sh run` quotes each argument; `--type 'CYC:text|'` uses `|`
  for Return; arguments must not contain `'`.
- The sim is ~380k clk_sys cycles/s alone, about half that during a Quartus
  flow.  The ROM's SCSI driver polls every 10 ms (330k cycles) per phase.
