## Gotchas learned this session

- Git Bash heredocs mangle backslashes (`\\n` in a Python heredoc became a real
  newline).  Use the Edit tool or write .py files for edits containing
  backslashes.  Check line endings (the .qsf had mixed CRLF/LF, which made an
  edit silently miss the SEED line).
- Killing a running Quartus flow is not permitted here: make sure the qsf/RTL is
  right BEFORE launching `build_only.sh` (~18-20 min full, ~5 min --check).
- `scripts/sim_wsl.sh run` quotes each argument; `--type 'CYC:text|'` uses `|`
  for Return; arguments must not contain `'`.
- The sim is ~380k clk_sys cycles/s; the real ROM needs ~107M cycles to the
  prompt, the fast ROM ~30M; the 16 MB DRAM test ~150M.
